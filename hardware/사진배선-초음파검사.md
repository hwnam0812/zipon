# 최신 사용자 배선 기준 초음파 단독 검사 — D7 / D11

## 최신 변경과 과거 설명의 구분

센서 뒷면에 HC-SR04와 Gnd / Echo / Trig / Vcc가 보입니다.
센서 쪽은 파랑 GND, 노랑 Echo, 주황 Trig, 빨강 VCC입니다.
**이번에 사용자가 Trig를 D7로 변경했다고 알려 주었습니다. Echo D11은 유지합니다.** 과거 사진의 UNO 연결부를 D8/D9로 읽었던 설명은 잘못되어 철회했습니다. 이후 사용자가 확인했던 D9/D11은 과거 연결이고 이번 코드의 기준은 D7/D11입니다. 사진만으로 모든 연결과 접촉 상태를 확정할 수는 없습니다.

현재 제공하는 V3·V4 통합 코드와 단독 검사 코드의 Trig를 모두 D7로 맞췄습니다. **배선 변경만으로 보드의 D9용 코드가 바뀌지는 않으므로 새 코드를 다시 업로드해야 합니다.** 핀 불일치를 과거 NO ECHO의 원인으로 단정했던 설명은 철회한 상태입니다. D7 변경·커패시터 추가로 NO ECHO가 해결된다는 뜻은 아니며, 전원·접점·부품 상태는 실물로 확인해야 합니다.

## 이번 검사에서 사용할 연결

| 초음파 핀 | 사진의 선 색 | UNO |
|---|---|---|
| VCC | 빨강 | UNO 5V와 직접 연결 |
| GND | 파랑 | GND |
| Trig | 주황 | **D7** |
| Echo | 노랑 | D11 |

**배선을 만질 때는 USB 및 다른 전원을 모두 분리하세요.** 220µF는 **센서 가까이 VCC와 GND 사이에 병렬**로 연결하며 +는 VCC, −는 GND입니다. **5V–220µF–VCC 직렬 연결은 사용하지 않습니다.** VCC와 GND의 직접 전원 공급은 유지하고 극성·5V보다 여유 있는 정격 전압을 확인하세요. 선 색·브레드보드 +/-만 믿거나 VCC를 디지털 핀에 연결하지 마세요. 이미 MQ-135를 분리한 단독 검사에서도 NO ECHO였으므로 동일 검사만으로 원인을 확정할 수는 없습니다.

병렬 배치 원칙 참고: [SparkFun Capacitors — Application Examples](https://learn.sparkfun.com/tutorials/capacitors/application-examples). 220µF가 해당 센서의 검증된 해결 용량이라는 뜻은 아닙니다.

## 실행

1. 노트북 연결 프로그램을 Ctrl+C로 종료합니다.
2. 위 배선과 핀 번호를 확인한 뒤 USB를 연결합니다.
3. Arduino IDE에서 ultrasonic_photo_check/ultrasonic_photo_check.ino를 열고 Arduino Uno와 현재 연결된 실제 USB 포트를 선택해 업로드합니다. 기존 포트 번호를 그대로 가정하지 마세요.
4. 시리얼 모니터를 115200으로 열고 정면 20~30cm 앞에 평평한 상자를 놓습니다. 단위·거리는 시험 배치 권장값이며 검증된 설치 기준은 아닙니다.
5. pulse_us=… distance_cm=…가 반복되는지 확인합니다. 값이 움직이는 물체에 맞게 달라지는지 살펴봅니다. 통신과 수치만으로 센서 정확도까지 보장하지 않습니다.

NO_ECHO는 완전한 응답 펄스를 받지 못한 상태입니다. ECHO_HIGH_BEFORE_TRIGGER는 트리거 전부터 Echo가 HIGH인 상태입니다. 어느 경우도 거리 0이나 문 열림으로 처리하지 않습니다. 단독 검사에서도 계속 실패하면 전원·접촉·센서·보드 입력을 실물 장비나 정상 부품과 비교해야 하며, 코드만으로 고장을 확정할 수 없습니다.

## 중요한 구분

이 코드는 **사진 기준 단독 검사 전용**입니다. 기존 스케치를 임시 대체하며 MQ-135 측정, 집온 연결, 사이렌 기능은 없습니다. 부저 D6은 LOW로 둡니다. 부저 종류에 따른 실제 소리는 검증하지 않았으므로 검사에는 부저도 분리하는 편이 좋습니다.

현재 통합 코드와 검사 코드는 모두 **LED D8 / Trig D7 / Echo D11** 기준입니다. 검사 후 집온으로 돌아갈 때는 사용하는 앱에 맞는 새 통합 스케치(V3 중계 또는 V4 직접 연결)를 다시 업로드해야 합니다. 검사 파일만으로 집온과 연결되지는 않습니다.

사진에 맞춰 통합 코드의 LED·부저·가스 핀까지 임의 변경하지 않았습니다. 먼저 초음파 신호가 나오는지 확인한 뒤 통합 연결을 진행하세요. 이 검사 코드는 UNO R3로 컴파일을 확인했으나 실제 센서에서는 시험하지 않았습니다.
