# 집온 · 우리 집 USB 모니터

MQ-135 원시 ADC와 초음파 거리의 변화를 살펴보는 **실습용 프로토타입**이에요. 농도·가스 종류·화재·누출·안전·실제 사람의 출입을 판정하지 않으며, 인증된 독립 경보기나 보안 장치를 대체하지 않아요. 가스·불꽃·연기로 시험하지 마세요.

## Streamlit 실행판

- 실행 파일: `streamlit_app.py`
- UNO가 연결된 컴퓨터의 지원 브라우저에서 USB를 직접 열어요. Streamlit이 다른 컴퓨터의 USB를 열지 않아요.
- 가족 비밀번호, 그래프, LED·부저 독립 제어, 감시 설정, 날짜·종류별 기록과 가져오기·내보내기를 제공해요.
- `DATABASE_URL`로 PostgreSQL을 연결해야 설정·이벤트를 계속 보관해요. 연결하지 않으면 접속별 임시 기록이라고 표시해요. 그래프는 접속 중 최근 600개만 보여요.
- 기존 앱·이전 기록·V3 스케치와 Python 중계는 보존돼요. 새 실행판이 기존 기록을 자동 이전하거나 기존 앱을 자동 실행하지 않아요.

GitHub 등록·Streamlit 설정·실행 방법은 [배포 안내](STREAMLIT-배포안내.md), 스케치 업로드·배선·실물 확인은 [V4 설치 안내](hardware/V4-USB-설치안내.md)를 따라 주세요.

## 배선과 통신

| 부품 | UNO 연결 |
|---|---|
| MQ-135 AO | A5 |
| 초음파 Trig / Echo | D9 / D11 |
| LED + 직렬 330Ω | D8 |
| 작은 수동 피에조 | D6 |

V4는 `9600 baud`의 줄 단위 JSON이에요. 기존 `ZIPON_AUTO_V3`와 섞어 쓰지 않아요. 센서 전원 분리·공통 GND·모듈의 실제 핀과 피에조 구동 조건은 설치 안내에서 먼저 확인해 주세요.

## 비밀과 기록

`ADMIN_TOKEN`과 `DATABASE_URL`의 실제 값은 실행 환경이나 Streamlit Secrets에만 설정해요. 저장소·채팅·UNO에 넣지 않아요. 실제 측정·가족 기록·업로드·내보낸 자료와 실행용 저장 파일은 Git에 올리지 않아요. `.streamlit/secrets.toml`과 `.env*`는 제외돼요.

## 확인 범위

검사는 임시 비밀번호·격리된 저장 공간·가상 USB만 사용해요. 실제 UNO·센서·빛·소리·전원 안정성, 외부 PostgreSQL 연결과 사용자 Streamlit 계정의 게시·USB 권한은 별도 확인이 필요해요. 앱 종료·절전·통신 단절 중 비상 알림과 완전한 오프라인 기록은 제공하지 않아요.

그래프는 함께 포함한 [Chart.js](https://www.chartjs.org/)를 사용하며, [MIT 라이선스 원문](streamlit_ui/vendor/Chart.LICENSE.txt)을 포함해요.
