# 집온 · 우리 집 USB 모니터

MQ-135 원시 ADC와 초음파 거리의 변화를 살펴보는 **실습용 프로토타입**이에요. 농도·가스 종류·화재·누출·안전·실제 사람의 출입을 판정하지 않으며, 인증된 독립 경보기나 보안 장치를 대체하지 않아요. 가스·불꽃·연기로 시험하지 마세요.

## Streamlit 실행판

- 실행 파일: `streamlit_app.py`
- UNO가 연결된 컴퓨터의 지원 브라우저에서 USB를 직접 열어요. Streamlit이 다른 컴퓨터의 USB를 열지 않아요.
- 가족 비밀번호, 그래프, LED·부저 독립 제어, 감시 설정, 날짜·종류별 기록과 가져오기·내보내기를 제공해요.
- 기본 보관처는 Supabase `zipon`이에요. `SUPABASE_SERVICE_ROLE_KEY`를 실행 환경에 등록하면 설정·이벤트·마지막 보고를 보관해요. 기존 `DATABASE_URL` 직접 연결도 유지해요. 연결 실패 시 임시 기록으로 바꾸지 않고 저장·제어를 막아요. 그래프는 접속 중 최근 600개만 보여요.
- 기존 앱·이전 기록·V3 스케치와 Python 중계는 보존돼요. 새 실행판이 기존 기록을 자동 이전하거나 기존 앱을 자동 실행하지 않아요.
- 메뉴는 **홈·기록·기기 관리·안심 시간·설정·실시간**이에요. 휴대폰 아래 메뉴도 같은 순서예요. 로고를 누르면 홈으로 돌아와요.
- 홈에서는 상태 요약과 LED·부저 빠른 제어를 사용해요. 부저는 한 번 더 확인하고 연결 전에는 제어할 수 없어요. 상세 제어는 접어서 보여줘요.
- 기록에서는 조회·필터·내보내기와 접힌 **기록 가져오기**를 사용해요. 기기 관리에서는 USB 연결·해제, 센서 점검, 이번 연결의 감시 시작·종료와 접힌 설치 안내를 사용해요.
- 안심 시간은 **문 알림 시간·출입 허용 시간**, 설정은 **기본 설정·문 기준 확인·가스 기준 확인**으로 나뉘어요. 어려운 숫자는 고급 설정을 펼쳐 조정해요. 수정 취소와 이동 전 미저장 확인을 제공하며, 기준 저장만으로 감시를 시작하지 않아요.
- 실시간에서는 측정값과 그래프를 확인해요. 기존 V3 화면에도 홈 메뉴와 설정 구분을 적용했지만, V3의 기록·시간표와 V4 USB 가족 공간의 기록·시간표는 자동으로 합치지 않아요.
- 홈에서 가스·문 상세 화면을 열어요. 가스는 농도 미측정·화재 위험 판단 불가이며 5,000ppm 기준을 적용하지 않아요. 문은 직접 확인한 닫힘 기준의 ±10cm를 표시용으로만 비교하고 무응답·오래된 값·기준 미확인은 확인 불가로 보여요. 기존 자동 감시 설정은 바꾸지 않아요.

GitHub 등록·Streamlit 설정·실행 방법은 [배포 안내](STREAMLIT-배포안내.md), 스케치 업로드·배선·실물 확인은 [V4 설치 안내](hardware/V4-USB-설치안내.md)를 따라 주세요.

## USB V4 배선과 통신 · 현재 확인한 배선

| 부품 | UNO 연결 |
|---|---|
| MQ-135 AO | A5 |
| 초음파 Trig / Echo | **D9 / D8** |
| 초음파 전원 | VCC는 UNO 5V 직결 / GND는 UNO GND |
| 커패시터 | **사용하지 않음** · 초음파는 위의 직접 전원 연결만 사용 |
| LED + 직렬 330Ω | D7 |
| 작은 수동 피에조 + 별도 직렬 330Ω | D6 · 전자석식 부저·스피커용 아님 |

V4는 `9600 baud`의 줄 단위 JSON이에요. 기존 `ZIPON_AUTO_V3`와 섞어 쓰지 않아요. 배선 변경 전 전원 차단·공통 GND·모듈의 실제 핀과 피에조 구동 조건은 설치 안내에서 먼저 확인해 주세요.

현재는 USB로 켠 UNO의 5V/GND를 초음파와 MQ-135가 공유하는 단기 시험 구성이에요. 외부 전원·9V 어댑터는 함께 연결하지 않아요. 전원 여유는 실물 확인 전이며 재시작·USB 끊김·보드나 케이블 과열이 있으면 USB를 분리해요. 외부 커패시터는 사용하지 않아요. **앱 연결용은 새 V4 파일만 사용해요.** 부팅 시 LED·부저·가스 감시는 꺼져 있고 ADC 0·1023·미측정에서는 새 가스 감시를 시작하지 않아요. ADC를 ppm으로 환산하지 않아요.

기존 V3 스케치·단독 사진 검사·그 다운로드와 설치 문서는 이전 핀 구성을 보존한 자료이며 현재 D9/D8 배선에 올리지 않아요. 현재의 기준은 [V4 USB 설치 안내](hardware/V4-USB-설치안내.md)예요. V3 통신과 기존 데이터는 이번 변경으로 바꾸지 않아요.

## 비밀과 기록

`ADMIN_TOKEN`과 `SUPABASE_SERVICE_ROLE_KEY` 또는 기존 `DATABASE_URL`의 실제 값은 실행 환경이나 Streamlit Secrets에만 설정해요. 저장소·채팅·UNO에 넣지 않아요. 실제 측정·가족 기록·업로드·내보낸 자료와 실행용 저장 파일은 Git에 올리지 않아요. `.streamlit/secrets.toml`과 `.env*`는 제외돼요. `SUPABASE_ACCESS_TOKEN`은 개발 중 관리에만 쓰며 앱 실행용 키로 사용하지 않아요.

## 확인 범위

브라우저 검사는 임시 비밀번호·격리된 저장 공간·가상 USB만 사용해요. Supabase 검사는 새 격리 공간에 합성 자료를 쓰고 전체 되돌리며, 실제 가족 기록은 검사 자료에 복사하지 않아요. 설정·이벤트·마지막 보고의 저장·재조회, 중복 방지·설정 충돌·공개 접근 차단을 확인했어요.

교체한 서버 전용 키로 실제 미리보기의 `zipon` 가족 공간이 열리는 것을 확인했어요. 새로고침과 독립된 두 화면에서 설정·기록·마지막 보고가 같았고, 가족 자료는 변경하거나 이전하지 않았어요. 사용자 Streamlit 계정의 게시와 Secrets 설정은 별도예요. 실제 UNO·센서·빛·소리·전원 안정성과 USB 권한도 사용자 환경에서 확인해야 해요. 특히 MQ-135의 가열·ADC 1023 문제는 해결 확인 전이에요. 앱 종료·절전·통신 단절 중 비상 알림과 완전한 오프라인 기록은 제공하지 않아요.

그래프는 함께 포함한 [Chart.js](https://www.chartjs.org/)를 사용하며, [MIT 라이선스 원문](streamlit_ui/vendor/Chart.LICENSE.txt)을 포함해요.
